# Meet Coco: Coco is now in England!

An animated, interactive introduction to a language-learning journey through England. Coco, an
African grey parrot animated with Rive, comes to life in a travel journal, lands in London, flies
the route on an illustrated map of the United Kingdom and Ireland, and visits the everyday places
where English gets used: the airport, a taxi, a café, a hotel, the landmarks and the markets.

It is a standalone project: Vite, React and TypeScript, with the Rive runtime for Coco, and SVG,
CSS and Canvas for everything else.

## Run it

Node 20 or newer.

```bash
npm install
```

```bash
npm run dev
```

Then open http://127.0.0.1:5173. For a production build:

```bash
npm run build
```

```bash
npm run preview
```

`npm run preview` serves `dist/` on http://127.0.0.1:4173. `dist/` is a static site, so any web
server can host it.

## Using it

- The story plays by itself, about a minute and a half across nine scenes. Use the controls at the
  bottom to pause, skip, jump to a scene, turn sound on or reduce motion.
- Keyboard: `←` and `→` change scenes, `Space` plays and pauses, `M` toggles sound.
- On the map you can drag, scroll, pinch or double-click to zoom, and open a stop for details.
  Exploring the map pauses the story until you choose "Continue the story".
- Sound is off until you turn it on. Everything you hear is synthesised in the browser with
  WebAudio (no recordings and no music).
- Reduced motion follows the system setting, and the motion button overrides it. Cameras stop
  moving, Coco holds still, and things fade in instead of flying.
- "START YOUR ADVENTURE" opens the interactive map, or a URL you set in `src/config/app.ts`.

For reviews, `?scene=4&t=9&pause=1` opens the story at a moment. `&reduced=1` forces reduced
motion.

## The story

| # | Scene | What happens |
| - | --- | --- |
| 1 | The journal | A journal on a desk, with a passport, a LONDON boarding pass and a paper map. The journal opens, a note writes itself and Coco appears as an ink silhouette. *"Every great adventure starts somewhere..."* |
| 2 | Meet Coco | The drawing comes alive, loops around the desk and lands on the ticket. *"Meet Coco." / "Your little companion on a big adventure."* |
| 3 | Arrival | A miniature London: Big Ben and Parliament, the London Eye, St Paul's, the Gherkin, the Shard and Tower Bridge, plus buses, cabs, boats and people. The camera pans and Coco lands on a street lamp. *"Well... looks like we're in England!"* |
| 4 | The map | The UK map assembles itself: ocean, coastline, land, terrain, water, forests, roads and rail, labels, then the stops. Coco flies in to London and the route draws itself to Edinburgh, with landings on the way. |
| 5 | London | The map dives into London and opens onto the street by Big Ben, with a bus, a black cab, a phone box and the Thames. Coco lands on the phone box. *"Let's explore London first!"* |
| 6 | Experiences | Six connected moments, each with its own light and an English phrase: airport and customs, taxi, café, hotel, landmarks, markets and shops. |
| 7 | Live it | Coco at passport control, in a taxi window, beside a cup of tea and flying to a street sign. *"Don't just learn English." / "Live it."* |
| 8 | The journey | Back on the map: London is stamped complete, the line runs on and Coco flies to Oxford. *"One journey. Countless experiences."* |
| 9 | Start | Sunset over the Thames. Coco perches on the title. *MEET COCO, "Learn English. Explore the world.", START YOUR ADVENTURE* |

Copy, timings and scene order live in `src/config/story.ts`, and the map's places in
`src/config/places.ts`.

## How it is built

```
src/
  App.tsx                 the story player: clock, crossfades, captions, controls, keyboard
  config/                 story copy and timing, places on the map, app settings
  scenes/                 one component per scene (S1-S2 share the desk)
  components/coco/        <Coco> (Rive), <CocoActor> (placement) and FlightPlan (paths)
  components/map/         <UkMap>, its projection, camera helpers and generated data
  components/stage/       a fixed-size scene scaled to cover the screen, with a camera
  art/                    the illustrations: London, the desk and the six vignettes
  audio/sound.ts          the WebAudio sound engine
public/
  coco.riv                Coco, generated by tools/coco/build_riv.py
  map/                    terrain and sea rasters, generated by tools/map/build_map.py
tools/                    the Python scripts that make coco.riv and the map data
scripts/shoot.mjs         screenshots of every scene for review
```

Every scene is a pure function of its clock time. That is why the story can pause, skip and be
screenshot at any moment, and why reduced motion only changes timings and cameras.

### Coco

Coco is a Rive character built from the original illustration. `tools/coco/cut_layers.py` cuts
the upscaled drawing into 11 layers and paints in what each moving part hides:

- the beak (upper beak, mandible and mouth interior), pupil, head, body, legs and tail
- the folded wing, plus a spread wing painted in its palette for flight

`tools/coco/build_riv.py` then writes `public/coco.riv` directly in the Rive runtime format (see
`tools/coco/riv.py`). The file contains:

- a rig of pivots: hips, neck, jaw, eyes and lid, tail, both wings and legs
- eight animations: `idle`, `perch`, `look`, `excited`, `takeoff`, `fly`, `land` and `blink`
- the state machine `Coco`

| Input | Type | Effect |
| --- | --- | --- |
| `flying` | bool | true: take off, then fly. false: land. |
| `perched` | bool | the settled perching idle instead of standing |
| `look` | trigger | looks around once |
| `excite` | trigger | a happy hop with a wing flutter and an open beak |

A second layer blinks on its own. The rest pose matches the source drawing within a mean of
1.2/255 per pixel.

```tsx
import { Coco } from './components/coco/Coco';

<Coco mode="fly" facing="left" cue={{ kind: 'excite', id: 1 }} style={{ height: 200 }} />
```

To move Coco along a path, `FlightPlan` times the takeoff and landing to the Rive animations, and
`<CocoActor>` places him by his feet.

### The map

`<UkMap>` is a self-contained component:

```tsx
<UkMap reveal={t} route={0.4} completed={['london']} current="oxford" interactive camera={cameraOn([-1.5, 52.5], 2)} />
```

It draws real geography, projected with a transverse Mercator centred on 4°W:

- Natural Earth 1:10m vectors: England, Scotland, Wales, Northern Ireland, Ireland (shown as a
  separate country) and the neighbouring coasts, plus lakes, rivers, major roads, railways and
  ferry routes
- shaded relief and sea depths rendered from AWS Terrain Tiles

The route follows real corridors: the M40 and Chiltern line to Oxford, then the West Coast Main
Line north. Labels use priority-based collision avoidance. The sea, the trees and the stops are
drawn by the component. It supports a staged reveal, drag, wheel and pinch zoom, keyboard pan and
zoom, hover and selection, info cards, a scale bar and a compass.

To rebuild the map data (Python 3 with numpy, Pillow and shapely; it downloads about 165 MB into
`tools/map/.cache`):

```bash
python3 tools/map/build_map.py
```

To rebuild Coco (Python 3 with numpy and Pillow):

```bash
python3 tools/coco/cut_layers.py && python3 tools/coco/build_riv.py
```

## Checking it

With the dev server running, `npm run shoot` screenshots key moments of every scene. It shoots a
1440×900 desktop and a 390×844 phone, and fails if the console shows any error or warning:

```bash
npm run shoot -- --out shots
```

Use `--only 4,5` to limit it to some scenes, `--at 4:2.5,9:8` for exact moments, and `--reduced`
for reduced motion.
